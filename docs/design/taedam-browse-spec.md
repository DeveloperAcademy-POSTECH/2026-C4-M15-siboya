# 태담 탐색 기능 스펙

- **상태**: review
- **작성일**: 2026-07-21
- **적용 범위**: 태담 탭의 대본 카테고리별 모아보기 화면
- **공통 계약**: [태담 공통 데이터 계약](./taedam-common-contracts.md)

## 1. 목적

사용자가 현재 실행할 수 있는 태담 대본을 카테고리별로 둘러보고 원하는 태담 종류로 이동하게 한다.

이 문서에서 **태담**은 앱의 태담 탭 첫 화면을 뜻하며, 특정 카테고리 상세는 [태담 종류 화면 스펙](./taedam-category-spec.md)에서 다룬다.

## 2. 화면 책임

- `ScriptRepository`에서 대본 목록을 읽는다.
- 대본을 `category`로 묶어 카테고리별로 표시한다.
- 카테고리 안의 표시 순서는 번들 JSON의 대본 순서를 유지한다.
- 카테고리를 선택하면 `TaedamCategorySelectionDTO`를 태담 종류 화면에 전달한다.
- SwiftData의 버킷리스트를 생성·수정·삭제하지 않는다.

## 3. 화면 입출력

| 구분 | 데이터 |
|---|---|
| 입력 | 없음 |
| 조회 | `ScriptRepository.fetchScripts()` |
| 표시 | 카테고리 이름, 카테고리에 속한 대본 요약 |
| 선택 결과 | `TaedamCategorySelectionDTO` |

## 4. 상태

- **loading**: 번들 JSON을 로드·검증한다.
- **loaded**: 하나 이상의 카테고리를 표시한다.
- **empty**: 유효한 대본이 하나도 없음을 안내한다.
- **failed**: JSON 디코딩·검증 실패를 사용자용 메시지로 변환해 표시한다.

## 5. 불변 조건

1. 빈 `category`는 표시하지 않는다. 이 경우는 로딩 실패로 처리한다.
2. 동일한 `category` 문자열은 하나의 그룹으로 표시한다.
3. 화면은 카테고리를 편집하거나 새로 생성하지 않는다.
4. 새로 저장된 버킷리스트는 이 화면의 카테고리 구성에 영향을 주지 않는다.
