# 태담 스펙 문서 인덱스

- **상태**: review
- **최종 수정일**: 2026-07-21

기존의 단일 태담 데이터 계약 문서를 공통 계약과 기능별 스펙으로 분리했다. 이 파일은 기존 경로를 유지하며 필요한 문서로 이동하는 인덱스 역할만 한다.

## 문서 구조

| 문서 | 책임 |
|---|---|
| [태담 공통 데이터 계약](./taedam-common-contracts.md) | 번들 JSON, 공통 플로우, DTO, 프로토콜, SwiftData 스키마, 저장 불변 조건 |
| [태담 탐색 기능 스펙](./taedam-browse-spec.md) | 태담 탭에서 대본을 카테고리별로 모아보는 화면 |

## 문서 작성 규칙

1. 모델·DTO·프로토콜 시그니처는 공통 계약에서만 정의한다.
2. 화면 전용 상태, 사용자 인터랙션과 표시 규칙은 해당 기능 스펙에 작성한다.
3. 전체 기능 경계가 바뀌면 공통 플로우와 영향을 받는 기능 스펙을 함께 수정한다.
4. 공통 계약과 기능 스펙이 충돌하면 먼저 의도를 확인한 뒤 두 문서를 한 번에 일치시킨다.

## 최근 기획 확정

- STT로 만든 버킷리스트는 키보드 텍스트 수정만 지원한다. 다시 말하기·STT 재시도 옵션은 제공하지 않는다.
- 하나의 태담 세션은 버킷리스트를 하나만 생성한다.
- 태담 요약 화면은 방금 생성한 버킷리스트 하나만 표시한다.
